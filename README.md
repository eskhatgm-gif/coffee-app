
# ☕ Brew Bliss Coffee

Brew Bliss is a modern coffee shop web application built with HTML, CSS, and JavaScript.

## 📌 About the Project

This project allows users to explore different coffee drinks, choose sizes, view prices, and place orders through WhatsApp.

## ✨ Features

- 🌐 Three languages: Kazakh, Russian, and English
- ☕ 12 different coffee drinks
- 📏 Three sizes: S, L, and XL
- 🔍 Search for coffee
- 🗂️ Filter coffee by category
- 🛒 Shopping cart with automatic total calculation
- 📍 Google Maps location: Shevchenko Street 97, Almaty
- 💬 WhatsApp ordering
- 📱 Responsive design for mobile and desktop
- 📝 Descriptions for every coffee drink

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Maps
- WhatsApp

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension.
4. Enjoy the application!
